Chapter 1: Excel Calculator Sheets

It started with a workbook. I built manual rating templates in Excel — trends, runs, starting pitching, bullpen, hitting — each with columns for splits (home/away, day/night, vs team, weather) and time windows (season, last N days). Every night I'd manually enter Fangraphs data into the sheets and read out the ratings.

Chapter 2: The Fangraphs Scraper

Manual entry didn't scale. Built a Python scraper against Fangraphs' splits leaderboard endpoints to auto-populate the workbook. Worked for a while, then Fangraphs changed their API shape and everything broke. Got tired of scraper-vs-website whack-a-mole.

Chapter 3: Building My Own Statcast Database

SQLite Statcast DB
  • Switched from scraping Fangraphs to pulling raw pitch-by-pitch data from Baseball Savant via pybaseball.
  • Ingest tables: plate_appearances, pitcher_game_stats, game_info, ingest_log, team_bullpen_stats, pitcher_roles.
  • Yesterday's Statcast pulled and inserted every morning, ~975 PA rows and ~100 pitcher game stats per game night.

Chapter 4: Rebuilding Fangraphs Stats From Scratch

Custom Advanced-Stat Calculator
Every stat recomputed from raw events using Fangraphs' actual formulas
  • Team hitting: AVG, OBP, SLG, OPS, ISO, BABIP, BB%, K%, BB/K, wOBA, wRAA, wRC, wRC+ with 3-year rolling park factors.
  • Starting pitching: K/9, BB/9, K/BB, HR/9, WHIP, BABIP, LOB% (Fangraphs formula with ER, not R), FIP, xFIP.
  • Annual constants (wBB, wHBP, w1B, w2B, w3B, wHR, wOBA_scale, lg_wOBA, lg_R_PA, FIP_constant, lg_HR_FB) sourced from Fangraphs Guts and version-locked per season.
  • Verified against Fangraphs to ~0.01 precision on veteran pitchers; tiny residuals traced to Statcast vs MLB Stats API aggregation differences.

Chapter 5: The Ratings Engine

Six-Category Weighted Rating System
  • Trends — 8 metrics from TeamRankings win-trend tables (rest advantage, coming off win/loss, home/away, fav/dog, division, league, etc.), each mapped to a game situation.
  • Runs — Team run-scoring metrics with per-rating windowing (calendar-days for R1, games for R2/R3).
  • Starting Pitching — 14 advanced metrics across up to 12 splits × 3 time frames (full / last 18d / last 42d).
  • Bullpen — Role-classified relief data with full / last 7d / last 14d windows.
  • Team Hitting — 13 metrics × 6 splits × 3 time frames per rating.
  • Bullpen Fatigue — 0-10 score based on top-4 reliever availability and bullpen IP over last 3/7 days.

Chapter 6: Three Rating Models

R1, R2, R3 — Each with Different Windows
  • Rating 1 — Original baseline. Runs uses last 7/15 calendar days. SP full/18d/42d.
  • Rating 2 — Adds 6 new granular SP splits (h @ h vs team, h @ h weather, h@h d/n weather, and combos). Runs windows: last 2/5 games. Sharp recency focus.
  • Rating 3 — All the R2 splits, plus SP window changes to full/13d/33d and runs windows to last 7/15 games.
  • Each rating has its own config folder (metric weights, scales, thresholds, weight_points, split_totals).
  • Website shows all 3 side by side; user can switch between them and see how the picks differ.

Chapter 7: External Data Sources

Multi-Source Fusion
  • Baseball Savant / Statcast — Pitch-by-pitch events, ingested nightly.
  • MLB Stats API — Today's schedule, probable pitchers, pitcher handedness, results grading (no auth required).
  • TeamRankings.com — Game logs, win trends across 26 situations, runs per game (scraped daily; emojis in print statements caused a week-long silent Unicode crash before I bulletproofed it).
  • The Odds API — Pregame moneylines, spreads, totals. Frozen at 8 AM so ROI is graded against actual pregame lines.
  • Open-Meteo — Temperature, wind, humidity, precipitation per venue.

Chapter 8: The Website

Dual GitHub Pages Sites
  • Analyst site (baseball.html) — Full drill-down. Click a game → click a category → click a metric → see all splits × 3 time frames with per-split ratings and weights.
  • Picks-lite site (picks.html) — Same picks, no metric drill-down. For sharing with people who don't want to see the guts.
  • Tabs: Picks, Gambling ROI (with "Bet Every Pick" vs "Strong Plays" split, weekly cards, by-week table), Postgame Compare, Perf by Metrics, Grand Total.
  • Cache-busting on every JSON fetch to defeat GitHub Pages CDN staleness.

Chapter 9: Daily Automation

7:00 AM Cron Pipeline (Windows Task Scheduler)
  • Ingest yesterday's Statcast → pull weather → classify pitcher roles → pull MLB bullpen stats → scrape TeamRankings → export hitting + SP resolved CSVs → export bullpen CSVs → sync exports to project root → build today's games.json → merge pregame odds → run all 3 ratings → publish to GitHub Pages.
  • Site is updated by ~7:20 AM every morning.
  • Mid-day regrade script also available for late-late-game refreshes.

Chapter 10: The Bugs I've Hunted

Debugging Log — Highlights
  • Trends context bug: 7 game-context fields (last_result, days_rest, fav_dog, is_division, is_interleague, etc.) were hardcoded as placeholders. Every trend metric was picking the wrong situation → wrong win %. Fixed with real derivation.
  • Name collision: Logan Gilbert vs Tyler Gilbert (and Bryce Miller vs Mason/Bobby/Erik Miller) — the player matcher was returning the first match on last name. Fixed with first-name refinement regardless of input format.
  • Split code order bug: exporter joined codes in resolved order (9_91_119), loader sorted before joining (119_9_91) → every multi-code split silently missed. R2/R3 lost half their SP splits until fixed.
  • LOB% used total runs (R) instead of earned runs (ER); FIP constant was 3.10 (2025 placeholder) when Fangraphs is at 3.12 for 2026; wRC+ had no park factor adjustment (Coors was wildly overrated). All fixed.
  • Hitting short/long window config for R1 had literal X placeholders (pa_lastX, pa_last2X) that never got substituted. Loader couldn't find lastXdays folder. Renamed columns to actual N values.
  • Export/sync gap: exports wrote to statcast_output/, engine read from project root, and only bullpen got synced. Hitting + SP were reading 10-day-stale files. Fixed sync to walk all export folders.
  • TeamRankings scraper Unicode crash: scripts printed rocket-launch emojis; subprocess default encoding cp1252 died on the first emoji. 7 days of stale game logs before I caught it. Fixed by forcing PYTHONIOENCODING=utf-8 on the subprocess env.
  • GitHub Pages CDN caching JSON responses aggressively. Site would show old data for 10+ min after publish. Added ?v=<timestamp> nonce to every JSON fetch — every page load bypasses the CDN cache.
  • Task Scheduler wake-from-sleep failing silently: desktop only supports S0 Modern Standby (not S3), which doesn't fire wake timers reliably. Solution: disabled auto-sleep entirely; monitor still turns off but machine stays responsive to timers.
